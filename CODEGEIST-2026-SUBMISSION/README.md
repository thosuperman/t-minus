# Codegeist 2026 submission package: T-Minus

T-Minus is go-live mission control for Jira: it runs an ERP, HR or finance cutover minute by minute.

- **Category:** Apps for Specialized Industries
- **Bonus:** Best Agents (Rovo)
- **Homepage and installation link:** https://tminus.hayaix.tech
- **Source:** https://github.com/thosuperman/t-minus

| Folder | What it is |
