# Codegeist 2026 submission package: T-Minus

T-Minus is go-live mission control for Jira: it runs an ERP, HR or finance cutover minute by minute.

- **Category:** Apps for Specialized Industries
- **Bonus:** Best Agents (Rovo)
- **Homepage and installation link:** https://tminus.hayaix.tech
- **Source:** https://github.com/thosuperman/t-minus

## Contents

| Folder | What it is |
|---|---|
| `DEVPOST/` | Start with `SUBMISSION_SHEET.md`: every field ready to paste, in form order. Sources: `Project_Title_and_Tagline.md`, `Project_Overview.md`, `Technologies.md`, `Submission_Fields.md`, `Installation_Instructions.md`, `Video_Description.md` |
| `VIDEO/` | The demo video (3:57, 1080p, male synthetic voice), narration script, subtitles, storyboard, `Video_QA.md` |
